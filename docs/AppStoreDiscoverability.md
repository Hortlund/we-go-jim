# App Store discoverability

Prepared for the release after 1.4.0. App Store Connect remains the source of
truth; this file keeps the approved copy reviewable in the repository.

## English (U.S.)

- Name: `We Go Jim`
- Subtitle (25/30): `Workout Tracker & Gym Log`
- Keywords (92/100):
  `lifting,strength,training,weights,reps,sets,routine,progress,offline,logbook,bodybuilding,PR`
- Promotional text (149/170):
  `Fast workout logging without an account. Build routines, track PRs and review progress — even offline. Free, private and built for lifters on iPhone.`

Do not repeat `workout`, `tracker`, `gym`, or `log` in the keyword field. Apple
already indexes words from the name and subtitle and combines them into phrases.

## Screenshot order and copy

The first three screenshots should explain the product before listing features:

1. `Fast logging. No account.` — active workout screen
2. `Build routines. Start in seconds.` — template/start workout screen
3. `See every PR and progression.` — progress or exercise detail screen
4. `Your history stays useful offline.` — history screen
5. `Train together, privately.` — Bros screen

Use short text at a size that remains readable in App Store search results. The
first screenshot should carry the primary conversion message; only a minority of
visitors swipe through the full gallery.

## Positioning to keep consistent

Use `We Go Jim — Workout Tracker` in website titles, social bios, directory
listings, and link anchor text. Keep the App Store product name as `We Go Jim` so
the brand remains clean; the subtitle supplies the high-intent category terms.

Primary promise:

> Fast workout logging. No account. No ads or tracking. Works offline.

Avoid claiming that no data exists outside the device: optional private iCloud
backup is available. `No tracking` and `local-first` are accurate; `all data stays
only on your phone` is not.

## After release

Record these weekly in App Store Connect for at least four weeks:

- App Store impressions
- Product page views
- Conversion rate
- First-time downloads
- Search-term ranking for `workout tracker`, `gym log`, and `träningsdagbok`

Change one major metadata or screenshot variable per release window where
possible. Otherwise there is no clean signal about which change helped.
