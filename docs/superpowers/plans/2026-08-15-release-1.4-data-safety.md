# WGJ 1.4 Data Safety Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Development fully isolated and make template editing, destructive deletion, reset, bootstrap, and settings persistence recovery-safe for WGJ 1.4.0.

**Architecture:** Value-only journals and revision coordinators protect unsaved template state without putting CloudKit on interaction paths. Destructive operations separate the committed local transaction from retryable artifact cleanup, while bootstrap and settings use explicit success-only boundaries. Build configuration remains the only source of environment identifiers.

**Tech Stack:** Swift 6, SwiftUI, SwiftData, Foundation file coordination, CloudKit, XCTest, Xcode 26.

## Global Constraints

- Keep WGJ local-first; draft writes and maintenance repairs never schedule CloudKit.
- Development uses only `se.highball.WeGoJim.dev`, `se.highball.WeGoJim.dev.WGJWidgetExtension`, `group.se.highball.WeGoJim.dev`, and `iCloud.se.highball.WeGoJim.dev`.
- Production uses only the corresponding identifiers without `.dev`.
- App and widget ship as marketing version `1.4.0`, build `1`.
- Preserve the user's unrelated `WGJ/WidgetShared/Localizable.xcstrings` change.
- Add no third-party dependency and perform no unrelated redesign.
